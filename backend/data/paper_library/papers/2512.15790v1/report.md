## 3. 研究背景

Agent-Based模型（ABM）是模拟复杂系统的强大工具，特别适合研究由局部交互涌现出的全局行为。然而，ABM常因缺乏系统化的探索协议而受到批评，导致难以评估结果的鲁棒性、普适性和政策相关性。传统的一因子一次实验（OAT）方法无法捕捉参数之间的非线性交互和随机性。全局敏感性分析（GSA）虽被视为标准，但基于方差的方法（如Sobol指数）需要大量蒙特卡罗采样，计算成本对于慢速ABM来说过高。此外，代理模型（如高斯过程、随机森林）在低维空间表现好，但难以扩展到高维或近似强非线性响应面。同时，现有方法常忽略ABM内在的随机性（aleatoric uncertainty）与代理模型近似误差（epistemic uncertainty）的区分，导致预测过度自信。因此，需要一种系统化、计算可行且可解释的工作流，以处理高维、非线性、随机性强的ABM探索问题。

## 4. 核心问题

如何设计一个系统化、可迁移且计算高效的工作流，用于：

- 对ABM的高维参数空间进行筛选和探索；
- 量化参数不确定性、模型内在随机性以及代理模型近似误差对输出变异的影响；
- 提供可解释的边界（如阈值、相变点），支持“what-if”推理和政策评估。

## 5. 方法详解

论文提出的多阶段工作流包含以下关键步骤（基于节选内容推断完整流程）：

1. **实验设计与随机性量化**：使用拉丁超立方抽样或其他空间填充设计覆盖参数空间。通过多次独立重复仿真（不同随机种子）量化ABM内在的随机性，即输出变异中无法由参数解释的部分。

2. **模型筛选（Model-Based Screening）**：采用线性方法（如多元线性回归）和基于树的方法（如随机森林或梯度提升）进行初步筛选，识别对输出有重要影响的参数，剔除不重要参数，降低后续代理建模的维度。

3. **机器学习代理模型**：基于筛选后的参数空间，训练非线性代理模型（如梯度提升机（GBM）、深度神经网络（DNN））来近似ABM输出。这些模型能够捕捉复杂的非线性关系、交互作用以及不连续区域（如临界点）。代理模型用于快速预测大量参数组合的输出，加速敏感性分析和不确定性量化。

4. **不确定性分解**：区分两类不确定性：
   - **随机不确定性（Aleatoric）**：来自ABM的随机种子和内在随机性，通过多次仿真估计。
   - **认知不确定性（Epistemic）**：代理模型在训练数据稀疏区域的不确定性，通过适形预测（Conformal Prediction）构建分布无关的有限样本预测区间，以特定置信水平覆盖真实输出。

5. **可解释性分析**：使用部分依赖图（PDP）和个体条件期望（ICE）等事后可解释工具，可视化参数如何影响输出，识别阈值效应和相变点，从而桥接准确预测与机制理解。
